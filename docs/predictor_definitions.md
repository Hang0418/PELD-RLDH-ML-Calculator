# Predictor Definitions

| Web input | Frozen source field | Definition and unit |
|---|---|---|
| Age | `Age` | Years at baseline. |
| BMI | `BMI` | kg/m². |
| Segmental range of motion | `sROM/degrees` | Degrees, measured using standing flexion–extension radiographs under the study protocol. |
| Multifidus cross-sectional area | `Cross_sectional_area/cm^2` | Bilateral multifidus CSA at L4–5, measured using ImageJ and averaged; cm². |
| Sacral slope | `Sacral_slope/degrees` | Angle between the sacral endplate and horizontal; degrees. |
| Pfirrmann group | `Pfirrmann_group` | Exactly one of `I–II`, `III–IV`, or `V`. |
| Modic group | `Modic_group` | Web `Absent` maps to frozen source code `无`; other levels are `I` or `II–III`. |

The source definition supplied by the study team says RLDH is MRI-confirmed recurrent disc herniation at the operated level, ipsilateral or contralateral, after at least one pain-free month, within two years of index PELD. The public data package cannot independently verify per-patient follow-up completeness.
